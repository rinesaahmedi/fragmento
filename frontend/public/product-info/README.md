# Product information assets

PDF files are grouped by product category and model:

- `dishwashers/<model>/`
- `refrigerators/<model>/`
- `extractor-hoods/<model>/`
- `washing-machines/<model>/`
- `ovens/<model>/`
- `hobs/<model>/`
- `lighting/<model>/`
- `uploads/` for newly uploaded, not-yet-classified PDFs

Keep product-information PDFs and energy-label PDFs together in the same model folder.
Use lowercase canonical filenames:

- `<model>-product-info.pdf`
- `<model>-elabel.pdf`

Public URLs mirror this folder structure, for example:

`/product-info/dishwashers/a-egspv597210/a-egspv597210-product-info.pdf`
